RAG 四大指标速查

先看问题发生在检索阶段还是答案阶段。

Context Recall

该找的证据有没有找全。

低分表示漏召回。检查知识覆盖、文档解析、查询改写、top-k 和阈值。

口诀：怕漏

Context Precision

找回来的证据是否相关、是否排在前面。

低分表示噪声多或排序差。使用 Rerank、元数据过滤、去重和优化切片。

口诀：怕杂

Answer Correctness

最终答案和参考答案是否事实一致。

它看“答得对不对”，可能受检索证据和生成能力共同影响。

口诀：事实对

Answer Relevancy

最终答案是否切中用户问题。

相关不等于正确：答案可能非常切题，但事实仍然错误。

口诀：是否切题
快速判断：没找到资料 → Recall；资料很多但很杂 → Precision；答案事实错 → Correctness；答非所问 → Relevancy。
